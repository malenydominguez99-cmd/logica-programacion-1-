# Lógica de Programación 1

## Descripción

Ejercicio práctico desarrollado en JavaScript que solicita tres números al usuario, analiza sus valores y muestra los resultados ordenados de mayor a menor y de menor a mayor.

También identifica si los tres números son iguales y, cuando son diferentes, determina cuál es el mayor, el intermedio y el menor.

## Objetivo

Practicar los fundamentos de la lógica de programación mediante el uso de variables, estructuras condicionales, arreglos y métodos de ordenamiento en JavaScript.

## Contexto

Ejercicio de práctica enfocado en el desarrollo del pensamiento lógico y la resolución de problemas mediante programación.

## Pasos realizados

1. Solicitar al usuario tres números mediante `prompt()`.
2. Convertir los valores ingresados a tipo numérico.
3. Comparar los números para comprobar si los tres son iguales.
4. Almacenar los valores en un arreglo.
5. Ordenar los números de mayor a menor y de menor a mayor utilizando `sort()`.
6. Identificar el número mayor, el intermedio y el menor.
7. Mostrar los resultados en la consola y en la página web.

## Resultado

Se desarrolló un programa capaz de recibir tres números, comparar sus valores y presentar los resultados ordenados.

Cuando los tres números son iguales, el programa muestra un mensaje que lo indica. En caso contrario, presenta ambos órdenes e identifica la posición de cada número.

## Aprendizajes

- Declaración y uso de variables.
- Conversión de datos mediante `Number()`.
- Uso de estructuras condicionales `if` y `else`.
- Comparación de valores mediante operadores lógicos.
- Manejo de arreglos.
- Ordenamiento de datos con el método `sort()`.
- Presentación de resultados mediante `console.log()` y `document.write()`.

## Tecnologías utilizadas

- JavaScript
- HTML5
